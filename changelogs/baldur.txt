This is Android 17 QPR0 with October 2026 security patches

Notes:
==============================
- LineageOS-based source.
- Always dirty flash at your own risk. If your device bootloops, revert to an older build that boots.
- Includes Dolby Atmos and Dolby Vision.

Device changes:
==============================
Games: Apply per-game thermal, CPU and GPU policies, thread placement and performance hints, with frame rate and scene feedback
Updates: Show pending system updates in Settings
Pen: Show the detected pen's product name in its notification

Unofficial ROM changes:
==============================
Display: Avoid a crash when a brightness request reaches a display that is no longer available
Game Space: Keep scrolling notifications readable over changing game backgrounds
Game Space: Restore brightness and gesture settings to the game session's user after switching users
Game Space: Keep Performance mode at full resolution and reserve resolution reduction for Battery mode, including previously added games
Game Space: Apply a game's mode when it is selected in settings or the game panel
Game Space: Change a running game's window ratio from a list and swipe twice across its black bars to move it between the center and bottom
Game Space: Add optional background-app cleanup when a game starts
Game Space: Hide the game bar, panel and overlays when the game leaves the screen while keeping the session grace period
Sidebar: Close the app drawer when it leaves the screen
Settings: Avoid a crash when a window is too short to draw its scrollbar
Floating windows: Restore visible windows after opening another app from Recents
Game Space: Restore charging settings correctly after bypass charging when no charging limit was previously set
Dynamic Island: Keep app icons at icon size when album artwork is unavailable
Mini windows: Fling mini windows between corners and make slow corner drags work for large floating windows
Lyrics: Share playback timing between the status bar and media popup, correct timing offsets when possible, keep untimed lyrics in the popup and hide missing lyrics
Game Space: Use the selected language for the Smart Pixels tile
Dynamic Island: Expand and collapse popups as a continuous morph of the island
Dynamic Island: Switch audio output from the media popup and scroll long titles, artist names and app names
Floating windows: Resize a window by pinching its top and bottom handles
Translations: Cover the new controls in Korean, Japanese, Russian, Simplified Chinese and Traditional Chinese
